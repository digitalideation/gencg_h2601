# Exercise Bank

These exercises are not tied to a particular session.

They can be used as short warm-ups, collaborative experiments, interruptions, debugging exercises or starting points for longer work.

## Collaborative exercises

### [Code Cadavre Exquis](./code-cadavre-exquis.md)

A collaborative coding exercise where a sketch is passed from one person to another. Each person continues the existing system without knowing exactly where it is supposed to go.

### Code Telephone

Observe a sketch without seeing its code, describe how you think it works, pass the description on, and reconstruct the system from the description.

### One Rule at a Time

Build a system collectively. Each person may add or modify only one rule before passing it on.

### Parameter Relay

Start from the same sketch. Each person changes only one aspect of the system, such as movement, scale, colour or probability.

## Constraints and experimentation

### Forbidden Function

Solve a familiar problem without using the most obvious function or technique.

### The Smallest Possible System

Create the most interesting behaviour possible with the fewest rules.

### One Variable, Ten Worlds

Choose one parameter and explore how far the system can change by modifying only that value.

### Mutate, Don't Improve

Take someone else's system and change its character without trying to make it "better".

### Design a Bad Tool

Create a tool that deliberately resists, misunderstands or complicates what it is supposed to do.

## Code reading and debugging

### The Bug Exchange

Introduce one interesting problem into a working sketch. Pass it on and investigate whether the bug should be fixed, understood or developed further.

### Human Algorithm

One person acts as the computer and follows instructions literally. Use the exercise to explore precision, ambiguity, repetition and conditions.
