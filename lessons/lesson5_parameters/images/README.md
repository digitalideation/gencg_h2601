# Session 5 image sources
These files are copied unchanged from the existing `main` branch, `lessons/lesson06_faces/images/`. They are not newly generated illustrations or newly cleared reproductions. The captions on `../faces.md` and `../examples.md` link to project documentation. Rights remain with the respective creators and photographers.

- `weird_faces.jpg`: Matthias Dörfelt, [Weird Faces](https://www.mokafolio.de/works/Weird-Faces).
- `face_trade.jpg`: Matthias Dörfelt, [Face Trade](https://www.isea-symposium-archives.org/art-events/face-trade-by-matthias-dorfelt/).
- `typeface01.png`: Mary Huang, [TYPEFACE](https://mary-huang.com/projects/typeface/typeface.html).
- `stranger_visions.jpg`: Heather Dewey-Hagborg, [Stranger Visions](https://deweyhagborg.com/projects/stranger-visions). The original large file is retained without recompression.
- `mas.jpg`: YesYesNo / Zach Lieberman, [Más Que la Cara](https://zachlieberman.medium.com/m%C3%A1s-que-la-cara-overview-48331a0202c0).

- `facemesh.jpg`: [Face Mesh sketch](https://editor.p5js.org/guma/sketches/IAlxLpyRd).
- `lenny.jpg`: [Lenny Face Generator](https://lenny-face-generator.textsmilies.com/).
